# ARKER Showroom

Typography-led static showroom for ARKER. Built with native HTML, CSS and JavaScript.

Website: https://jatu3.github.io/arker-showroom/

## Development

```sh
cd project/web1/site
npm run dev
npm run check
npm run build
```

GitHub Actions validates and deploys the static `dist` directory. Google Apps Script source is provided in `apps-script` and deployed separately. Form submissions are enabled only when the deployed endpoint is configured.
